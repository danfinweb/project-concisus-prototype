# Impact report — 2026-11-24, second update

**Mode:** update · **Design baseline:** `75e776f` → `3aac08f`

This refresh brings in the second batch of tactical and tactical-AI decisions and the item list's new Mods
table. The spec now has 406 IDs: 1 new (ITM-033), 22 changed, none removed. 15 tactical and 6 tactical-AI
open questions are resolved. Every `/data` table these sections touch is still empty, so nothing fails
validation.

## What changed in the design

- **Reactions and turns:**
  - any visible action triggers reactions (firing, reloading, using an item, newly opened sightlines)
  - "cover hit" is defined
  - take-cover ties are settled
  - a soldier with 2 stamina may sprint
  - soldiers leave the map one by one
- **Neutrals and AI:**
  - neutrals react by a fixed rule (civilians flee to the nearest exit, armed neutrals take cover)
  - a rejected AI command is retried up to 3 times
  - the retreat threshold counts only dead soldiers and those who left the map
  - rank ties go to the highest average attribute
  - reinforcements are optional
  - a player-controlled VIP moves only, set in the tactical map request
- **Weight:**
  - carry capacity 15 + 0.3 × Strength + 0.1 × Endurance kg
  - Strength scales the over-encumbrance penalty
  - heavy assault armour −5 AP
- **Weapons:**
  - burst length per weapon
  - the fire AP override replaces only the type default
  - no vaulting while carrying or dragging
- **Map:**
  - large buildings are 3+ floors plus warehouses and plant halls, with a stairwell by the main entrance
  - a blast reaches only edges with no full cover in between
  - the shooter's own obscuring tile never counts
- **Item list:** Mods table (red dot, 4× scope, sniper scope, laser).
