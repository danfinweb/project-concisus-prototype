### Where the spec now differs from module code (for the module sessions)

- **tactical-ai:**
  - A weapon type with no `roles.byWeaponType` entry gets no role. Core falls back to `flank`.
  - The AI should read the weapon in the `activeWeapon` slot. Core reads `weapon1`.
  - The adapter pins the old interface versions and needs `/integrate`.
- **strategic-ai:** the tests assume an AI squad can't cancel a move in transit. The spec now lets it cancel
  (finding 9 above). Its test views also lack the now-required `mapShape` (1 Test Lab failure).
- **Test Lab after this cleanup:** shared 7/7, management 82/82, strategic-ai 60/61, tactical-ai 69/76 (the 7
  are adapter version-pin checks: view 0.7.0 vs 0.8.0). Strategic and tactical fail only because `core/` is
  not built yet.
- **management:** `core/requests.js:153` reads `a.act` from battle_result acts; the field is `type`.
