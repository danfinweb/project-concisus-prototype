# design/ — ground truth, read-only

Markdown exports of the live Claude Docs. Only the user edits the design, in the live docs; this folder is
refreshed by exporting them again (Export → Markdown, or ask Claude to re-export). Never hand-edit these files.

The GDD is split along the game's modules: `design.md` holds the overview, factions & campaign and the module
map; each module has its own doc.
